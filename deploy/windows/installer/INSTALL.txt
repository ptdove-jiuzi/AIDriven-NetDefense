AIDriven NetDefense 0.0.1-rc.1（Windows x64 测试版）
作者：PT-dove

============================================================
这是什么
============================================================
这是给你自己测试用的内部测试包，不是对外发布版本。
不含代码签名，不含服务注册，不含任何联网下载。
开机自启是可选项，默认不勾选，只有你自己勾了才会写入。

安装后你能验证的是：
  · 程序文件完整落盘、路径可选、可覆盖升级、可干净卸载
  · 桌面外壳 AIDrivenNetDefense.exe 能启动，托盘出现
  · 内置 Node 运行时能启动
  · worker 能通过预检（environment / profile / 清单校验）

安装后你暂时验证不了（因为载荷里本来就没有）：
  · 没有模型 broker，涉及模型的调用会失败，这是预期行为

============================================================
怎么安装
============================================================
1. 把压缩包完整解压到一个普通目录（不要在压缩包里直接双击）。
   必须保证 Setup.cmd、Setup.ps1、payload\ 三者在同一层。
2. 双击 Setup.cmd。
3. 窗口里会显示安装路径，默认 C:\Program Files\AIDriven NetDefense。
   点「浏览…」可以换成任意目录（不要选盘符根目录或 Windows 目录）。
4. 如果这台机器以前装过，窗口顶部会显示：
   「检测到已安装：<版本>（<路径>）」
   并且路径框会自动填上次的安装路径 —— 直接点「开始安装」就是覆盖升级，
   data\ 与 install\ 会保留，不会清掉。
5. 勾选项：
   · 「创建桌面快捷方式」默认勾选
   · 「开机自动启动」默认**不勾选**，勾了才会写入当前用户启动项
     （HKCU\Software\Microsoft\Windows\CurrentVersion\Run）
6. 点「开始安装」，等进度条走完（视磁盘而定）。
7. 装完：开始菜单 → AIDriven NetDefense → 直接启动程序；
   桌面快捷方式同样指向 AIDrivenNetDefense.exe。
   需要自检/排错时走二级菜单：开始菜单 → AIDriven NetDefense → 诊断 → 自检。

============================================================
关于「未知发布者」提示
============================================================
这个包没有购买代码签名证书，所以 Windows 可能提示
「Windows 已保护你的电脑 / 未知发布者」。
这是开源免费分发的正常现象，不是安装失败：
  点「更多信息」→「仍要运行」即可。

如果提示来源不是你自己的解压目录，或者 SHA256 对不上，请不要继续。

============================================================
怎么升级
============================================================
拿到新版本后，照常解压、双击 Setup.cmd。
它会自动读出上次的安装路径并预填，点「开始安装」直接覆盖升级。
不需要先卸载。
覆盖升级只覆盖程序文件，data\ 原样保留（安装器会核对升级前后的数据文件指纹）。

============================================================
怎么卸载
============================================================
方式一：Windows 设置 → 应用 → 已安装的应用 → AIDriven NetDefense → 卸载
方式二：双击 Setup.cmd → 点「卸载」
        会问是否保留数据目录（data\ 与 install\）：
        选「是」保留，选「否」全部删除。
方式三：命令行静默卸载（连同数据一起删除）
        Setup.cmd /S /uninstall /DIR="D:\你的安装路径"

卸载时会先结束该安装目录下正在运行的程序（含 daemon 子进程，
按可执行文件路径与命令行匹配），再删文件，最后清掉开机自启项。
开始菜单和桌面快捷方式会一并移除。

============================================================
静默参数（给脚本和冒烟测试用）
============================================================
  /S            静默安装
  /DIR=<路径>   安装目录
  /NOREG        不写卸载注册表项
  /NOSHORTCUT   不创建开始菜单与桌面快捷方式
  /AUTOSTART    写入开机自启项（默认不写）
  /uninstall    卸载（与 /S 连用）

例：
  Setup.cmd /S /DIR="D:\tmp\aidn" /NOREG
  Setup.cmd /S /DIR="D:\tmp\aidn" /NOREG /AUTOSTART
  Setup.cmd /S /uninstall /DIR="D:\tmp\aidn" /NOREG

============================================================
校验下载完整性
============================================================
在同目录打开 PowerShell，执行：

  Get-FileHash .\payload\manifests\files.sha256 -Algorithm SHA256

把结果与 SHA256SUMS.txt 里对应的那一行比对，一致即未被改动。

============================================================
日志与排错
============================================================
安装/卸载日志：%TEMP%\AIDriven-Setup-<时间戳>.log
自检输出：直接看「自检」窗口，最后一行是 exit code。

常见问题：
  · 提示 payload\bundle.json not found
      → 压缩包没解压完整，重新解压，别只拷 Setup.cmd。
  · 提示 载荷里找不到 AIDrivenNetDefense.exe
      → 你拿到的是 v13 载荷（没有桌面入口）。安装器只接受 v14 桌面载荷，
        换新包，别用旧包重试。
  · 安装到一半失败
      → 看日志里的 robocopy 退出码；>=8 表示复制失败，通常是权限或磁盘空间。
  · 自检报 AEGIS_ANALYSIS_CWD must equal process cwd
      → 不要手动改「启动-自检.cmd」里的 cd 行，它必须停在安装根目录。
  · 自检报 HOME / TMP 相关错误
      → 说明环境变量被外部覆盖了，用开始菜单里的「自检」启动，别在自定义
        环境里直接跑 worker。

============================================================
当前限制（不要当成缺陷）
============================================================
· 仅 Windows x64，未验证其他平台
· 未签名
· 不做服务注册、不做自动更新
· 不写 ProgramData，不写系统服务，不改 PATH
· 开机自启只写当前用户 HKCU 启动项，卸载时清除；不会写入 HKLM
· 卸载不删除 %LOCALAPPDATA%\AIDriven NetDefense 下的自检临时目录，
  需要的话可手动删除
