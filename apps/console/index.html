连接

只读数据面
数据来源 决定 /api/v1/* 打到哪里

同源代理：本页与 /api/v1/* 由同一个本地服务提供，token 由代理注入，前端不持有任何凭据。 直连：直接请求 http://127.0.0.1:端口，必须自带 Bearer token。

daemon 地址 仅直连模式使用

只接受 http://127.0.0.1:端口 或 http://[::1]:端口。daemon 只监听回环， 且响应不带 Access-Control-Allow-Origin，所以跨端口的直连在浏览器里通常会被拦下； 这一步的失败信息会在下方自检里如实显示。

Bearer token 仅直连模式；不写 URL、不写 localStorage

token 只保存在本标签页的 sessionStorage（关闭标签即失效），并以 Authorization: Bearer 头发送。 CSRF 证明 x-aegis-csrf 只在内存中、只随状态变更请求发出，来自 /api/v1/status 的 csrf_token。
